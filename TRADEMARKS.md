# The LifePeek name and logo

The code is open (Apache-2.0) and the teaching content is open (CC BY 4.0).
**The name "LifePeek" (in any script or spelling), the logo and the app icon are not.**
Neither licence gives you permission to use them. Apache-2.0 says so itself in section 6.

This is not about stopping anyone. Teachers and students need to know which site is the one where
mistakes get reported and fixed. If a changed copy carries the same name, nobody can tell them apart.

## You may, without asking

- Say what LifePeek is and link to it: "We used LifePeek (https://lifepeek.vercel.app) in class."
- Write about it, review it, teach with it, and show screenshots of the real app.
- Say your project is "based on LifePeek" or "forked from LifePeek", as long as your own name is the main name.
- Run an unchanged copy for your own school or class (for example on a school server).
  If you change anything, see the next section.
- Keep the NOTICE file and the "Made by" credit. Apache-2.0 requires the NOTICE file anyway.

## Please don't

- Publish a **modified** version (a fork, a hosted copy, an app-store app) under the name LifePeek (in any script)
  or a name that looks or sounds confusingly similar.
- Use the logo or app icon for your copy.
- Suggest that your copy, course, product or organisation is official, endorsed by or connected
  to LifePeek when it isn't.
- Register LifePeek as a domain, app-store name, social media handle or company name.

## If you fork

1. Pick a new name and replace "LifePeek" in the UI, the PWA manifest
   (`apps/web/vite.config.ts`), `package.json` names and the i18n files.
2. Replace the logo and icons in `apps/web/public/`.
3. Keep `LICENSE`, `NOTICE` and `LICENSE-CONTENT.md`, and add your own copyright line.
4. "Based on LifePeek by Sarthak" in your About page is welcome and is the right way to credit.

## Status

"LifePeek" is not a registered trademark. Before any app-store release, search IP India
(Classes 9 and 41). This file states how the maintainer asks the name to be used, following
the common practice of open-source projects such as Mozilla Firefox.
